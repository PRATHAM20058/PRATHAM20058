[ PROJECTS ]

1. PRAXES 2K26 – College Festival Registration Portal

Tech Stack: React 19, Vite, Framer Motion, Google Apps Script, html2pdf.js, Vercel

Links: GitHub | Live Demo

Overview: Serverless, high-performance Single Page Application (SPA) designed to manage event discovery and team registrations for a college-wide technical festival, entirely bypassing traditional backend infrastructure costs.

Key Features & Technical Highlights:

Interactive Frontend & Micro-Interactions: Built with React 19 & Vite. Features fluid page transitions, interactive progress bars, and a custom "Curtain Reveal" intro animated with Framer Motion.

Dynamic Registration Engine: Multi-step team registration form equipped with conditional step-bypassing (e.g., auto-bypassing payment for host-college students) and dynamic form validation algorithms.

Serverless Backend Integration: Custom webhook created with Google Apps Script to securely ingest and flatten multi-participant JSON payloads into real-time entries in Google Sheets.

Client-Side PDF Ticket Generation: Dynamically generates and renders personalized, downloadable PDF participation passes on the client side using html2pdf.js.

Admin Dashboard: Utilizes the Web Storage API (Local Storage) for state management and mock CRUD operations on event schedules, rules, pricing, and role-based access.

SPA Deployment: Optimized routing and client-side page rewrites configured via custom vercel.json rules.

2. Stationery Shop Management App — Frontend

Tech Stack: Ionic 8, Angular 20 (Standalone Components), Capacitor 8, SQLite, Node.js, Express, MySQL

Links: GitHub

Overview: Cross-platform web and Android application featuring a complete offline-first local cache + sync queue backed by SQLite to ensure continuous POS/billing operation when disconnected from the server.

Key Features:

Billing & POS: Cart creation via search/category, per-line discounts (fixed amount or percentage), directly editable quantities, and payment flows (Paid, Pending, Partial).

QR / Barcode Scan-to-Cart: Direct scanning via @capacitor-mlkit/barcode-scanning on search & SKU forms with image gallery fallback.

Payment Integration: Supports Cash, UPI, and Cheque (with dedicated cheque number tracking).

Inventory & Items: Complete CRUD with category filtering, low-stock visual badges, SKU lookup, and godown/location-based search matching.

Bill History & Reports: PDF invoice generation/sharing, status filtering, sales charts, and top/low selling/stock analytics for 7/30-day windows.

Enterprise Integration: Configurable environment fields for automated company GSTIN and header printing on receipts.
